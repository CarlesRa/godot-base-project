# 🎮 Godot 4 - Game Jam Base Project

¡Proyecto base y plantilla de inicio para Game Jams en **Godot 4**! 🚀

Diseñado para acelerar el desarrollo durante las primeras horas de una jam, proporcionando una configuración optimizada para la Web y buenas prácticas de desarrollo.

---

## 🛠️ Especificaciones Técnicas

* **Motor:** Godot 4.x (Compatibility Renderer / WebGL 2.0)
* **Lenguaje:** GDScript
* **Target Principal:** Web (itch.io / Newgrounds) & Desktop (Linux, Windows, macOS)
* **Control de Versiones:** Git
